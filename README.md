# RR Cycle Mart — Landing Page

Landing page for RR Cycle Mart, a bicycle shop on Varthur Main Road,
Marathahalli, Bengaluru.

Plain HTML/CSS/JS, no build step — `index.html` is the entry point.
Same design system as the Global Enterprises site (also a cycle shop),
same vermillion/paper palette, content rewritten for this business.

## Local preview

```
python3 -m http.server 8000
```

Then open http://localhost:8000
